# Private single-world alpha integration plan

This plan drove the first integration of the persistent four-inhabitant world,
paired Godot client, hosted cognition roles, content state and richer-world
summaries. That integration exists, but the original document mixed completed
work, current product status and future promises in one place.

It is retained as historical context and no longer owns current truth.

- See [current product state](../status/current-state.md) for what is playable,
  thin, fixture-only or planned.
- See the [roadmap](../planning/roadmap.md) for the **Living Settlement**
  milestone and later outcomes.
- See [known bugs](../bugs.md) for confirmed UI, cognition and starter-content
  gaps.
- See the [Phase 5 ledger](phase-5.md) for bounded content-governance evidence.

The still-valid product boundary is a private single-world game with a Godot
client and authoritative host. Multiplayer/public-world work remains deferred,
provider credentials remain host-only, and arbitrary executable mods remain
disabled until their sandbox question is explicitly resolved.
