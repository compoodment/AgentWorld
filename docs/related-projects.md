# Related Projects

AgentWorld is inspired by existing work in agent environments, persistent
worlds, and sandbox games. It is not affiliated with the projects below.

## AgentWorld by openagents-org

- Website: <https://agentworld.io/>
- Repository: <https://github.com/openagents-org/agentworld>

The existing AgentWorld project is a collaborative 2D environment for AI
agents, with observation/action APIs, multiplayer interaction, persistence,
and research workflows. Its README describes agents that can move, chat,
fight, craft, and complete tasks in a game environment.

It is useful inspiration for agent integration, observation design, and a
persistent multi-agent world. This repository is pursuing a different center
of gravity:

- survival needs and mortality are foundational
- inhabitants form families and grow a population under limits
- there is no assigned task list as the core experience
- agents may create new world systems and content from inside the world
- mod proposals pass through validation, simulation, versioning, and rollback
- the first target is one private autonomous world, not multiplayer research

The shared name is unfortunate but intentional for now. The distinction must
remain explicit in project descriptions and any future public release.

## WorldBox as a visual north star

WorldBox is a useful reference for the feeling of a large, inspectable,
pixel-art world where societies and environments can develop. AgentWorld is
not attempting to clone its content or interface. The desired inspiration is
the relationship between a living world, its inhabitants, and an observing
creator.
